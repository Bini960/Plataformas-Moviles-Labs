# Plataformas Móviles - Laboratorios



Repositorio de laboratorios del curso de Programación de Plataformas Móviles. Cada laboratorio tiene su propio proyecto de Android Studio.


## Estructura



- lab4 — Frontend básico con Jetpack Compose



## Herramientas



\- Kotlin

\- Android Studio

\- Jetpack Compose


**Para ejecutar cualquier laboratorio:**

1\. Abrir la carpeta del laboratorio correspondiente en Android Studio.

2\. Esperar a que Gradle sincronice las dependencias.

3\. Ejecutar en un emulador o dispositivo físico con el botón "Run".
